

# E150 - Evo UST
cathay_hackathon_2025

**One line summary:** EvoGreen – an Evolutionary Green AI Platform for The Cathay Group

EvoGreen serves as both a GreenPoints reward system and an AI‑powered end‑to‑end travel planner. Leveraging our AI Itinerary Planner, users receive personalized recommendations for eco‑friendly activities along with sustainable in‑flight options to choose from. Each action is incentivized through GreenPoints, helping travelers build lasting sustainable habits and connect within a growing green community.
